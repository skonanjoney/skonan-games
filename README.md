# SKONAN GAMES

A simple GitHub Pages-ready collection of SKONAN browser games.

## Folder structure

- `index.html` — games collection homepage
- `games/` — finished games
- `games/SKONAN_SUDOKU.html` — current Sudoku game

## Adding another game

1. Put the new HTML file inside `games/`.
2. Open `index.html`.
3. Copy a game card and change its name, description and link.
4. Save.
5. Upload/push the whole project to GitHub.

## GitHub Pages

On GitHub:
1. Create a repository.
2. Upload all files while preserving the folder structure.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the main branch and `/ (root)`.
6. Save.

The collection homepage will then be served from `index.html`.
