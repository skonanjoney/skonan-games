SKONAN GAMES
============

Open index.html in a browser.

Current game:
- SKONAN SUDOKU -> skonan-sudoku.html

To add another game:
1. Put the game's HTML file in this same folder.
2. Add a new game card in index.html.
3. Set the PLAY link to the new HTML filename.

This collection works offline and does not require a server.
